Mode d'emploi

Au quotidien

  • Aujourd'hui : ce qui est en retard ou dû aujourd'hui. Clic sur le cercle = valider, clic sur la date = reporter.
  • Tâches : ajout rapide en haut (Entrée), « Tâche complète » pour client, projet, rappel, récurrence.
  • Note (en bas à droite) : le calepin pour griffonner. « → tâche demain » transforme la ligne où se trouve le curseur en tâche urgente pour demain.
  • Objectif de l'année : dans Pipeline → Tableau de bord, tape ton objectif en MWc signés ; la barre montre le signé et, en plus clair, ce qui est en contrat.
  • Aperçu au survol : laisse la souris une demi-seconde sur une société, un contact ([[lien]]) ou le nom d'un client dans le pipeline : une mini-fiche s'affiche (contacts, pipeline, tâches, dernier RDV).
  • Réglages partagés : avec la synchro GitHub, tes vues enregistrées, les points posés dans le réseau, les filtres du réseau, l'objectif de l'année et les phases de la vue réunion sont les mêmes sur l'ordinateur et le téléphone.
  • Widget (en bas à gauche) : tes tâches dans une petite fenêtre détachée, qui reste au-dessus des autres (Outlook, Excel…) sur Chrome et Edge ; ailleurs, une petite fenêtre séparée.
  • Ma semaine (carte en haut d'Aujourd'hui, ou Ctrl+P « semaine ») : signés, offres remises, dossiers qui ont avancé, nouveaux, RDV, tâches faites et la semaine prochaine — « Copier pour mail / Teams » pour l'envoyer tel quel.
  • Note du jour : chaque matin, la note garde ses lignes non cochées ; la veille est rangée, datée, dans l'historique (bouton horloge de la note, ou Ctrl+K pour y chercher).
  • Liens : tape [[ dans une tâche, la note ou un commentaire de contact pour citer un contact, une société ou une installation. Le nom devient cliquable, et sa fiche affiche « Mentionné dans ».
  • Vues (bouton « Vues » dans Tâches et Pipeline) : des filtres prêts (en retard, en attente des autres, offres en attente depuis 15 jours, dossiers sans tâche…) et les tiens, à enregistrer.
  • Réseau : toutes les connexions entre sociétés, contacts, installations, tâches, RDV et contrats. Clic = détails, double-clic = la fiche ; « Voir dans le réseau » depuis une fiche montre son voisinage. Les noms s'affichent au survol (le point et ses voisins). Survole un filtre pour mettre ce type en avant, ◎ pour le garder ; « Tous les acteurs » filtre par type de société ; Maj + glisser (ou « Sélection ») entoure plusieurs points, qu'on déplace ensemble ; « Vue d'ensemble » (ou Échap) remet tout à zéro. Glisse un point pour l'isoler : ses liens suivent et il reste là où tu le poses ; « Libérer les points » remet la disposition automatique.
  • Archive : tâches validées et corbeille (rien n'est perdu).

Raccourcis

  • Ctrl+Z annuler la dernière action (plusieurs fois pour remonter), Ctrl+Maj+Z rétablir · Ctrl+P toutes les actions (palette de commandes) · Ctrl+K rechercher partout (tâches, contacts, sociétés, pipeline, Portefeuille) ; Entrée ouvre le premier résultat (sans résultat, crée la tâche) · n ajouter une tâche · Ctrl+F chercher dans l'onglet affiché (tâches, contacts, pipeline, archive) · p ouvrir la note
  • j/k se déplacer · Entrée valider la tâche sélectionnée · e la modifier · Échap fermer · ? cette liste
  • Dans une fiche du pipeline : Entrée passer à l'étape suivante (et Entrée encore pour confirmer) · 1…9 cocher la liste de l'étape · n notes express · a mode appel

Le chemin d'une opportunité

Pré-qualif→Qualification→ Go →Offre→Contrat→Onboarding→En service
  1. Pré-qualif : un client rencontré, pas encore de projet. « Projet identifié » crée l'installation.
  2. Nouvelle opportunité : choisis le client puis le contact (existant ou nouveau), puis colle le mail ou dépose un .msg, un .eml ou l'Excel du producteur. Les champs se remplissent ; ceux à compléter sont signalés en jaune.
  3. Une fiche par installation. Plusieurs centrales dans le même mail ou le même Excel = plusieurs installations, regroupées dans une demande de pricing.
  4. Quand tu valides la tâche liée, l'app propose l'étape suivante et crée la tâche. Les étapes des autres équipes (Ops, SC, Jur, Dir, d'après le RACI) deviennent des tâches « en attente » pour relancer.
  5. Go : la demande de pricing s'ouvre avec l'objet, les codes affaire et le texte du mail. La fiche « Caractéristiques Centrales » et le brouillon Outlook se font avec Claude (skill demande de pricing).
  6. Sorties possibles à tout moment : No Go, Perdu, Abandonné (bouton « Sorties » pour les revoir, « Réactiver » pour revenir).

Mettre à jour les Excel partagés

  • Caractéristiques centrales (dans chaque fiche, même d'une seule centrale) : toutes les lignes du fichier, à remplir sur place. « Obligatoires » n'affiche que ce dont le pricing a besoin. Comme dans Excel, tire le petit carré vert de la case active vers les autres centrales (ou vers le bas) pour recopier la valeur.
  • Liste (bouton dans le Pipeline) : toutes les installations dans un tableau, triable en cliquant sur une colonne, avec les totaux ; la recherche et les vues s'appliquent, un clic ouvre la fiche.
  • Excel ⇄ (bouton du Pipeline, sur l'ordinateur) : pour chaque installation, ce qui a été envoyé au Pipe et au Suivi (BDD) — pas envoyé, modifié depuis l'envoi, à jour — et, après « Relire les Excel » (pont Excel), ce qu'un collègue a changé dans les fichiers : « Reprendre dans l'appli » ; un statut Gagné / Perdu du Suivi se reporte sur l'étape en un clic. « Envoyer au Pipe / au Suivi » envoie tout ce qui attend (jamais une case modifiée par un collègue sans te demander). Le nombre sur le bouton = ce qui reste à traiter.
  • Glisser-déposer : attrape une carte ou le bloc d'une demande, il suit la souris ; lâché sur une colonne, l'appli demande l'étape exacte (Échap pour annuler).
  • Grouper : coche la petite case en haut à droite des cartes ou blocs à réunir (ou Ctrl+clic), autant que tu veux, puis « Grouper » dans la barre en bas ; le plus gros bloc accueille les autres. « Dégrouper » (au survol du bloc, ou dans sa fiche) les sépare.
  • Blocs : le crayon (au survol) donne un nom au bloc, affiché sous le producteur ; les totaux (installations · MWc) sont à droite ; au-delà de 3 installations, la liste se replie (« ▾ N installations » pour la déplier).
  • Pricing indicatif ou engageant : une seule étape « Pricing », nommée d'après l'offre demandée (« Offre demandée : Indicative / Engageante » dans « Maintenant ») ; pour une offre engageante, le « Pricing ferme » du contrat est inclus et sauté. Le Go passe directement au pricing et ouvre la fiche sur le mail de demande.
  • Étape suivante : la fenêtre propose aussi de clore la tâche de l'étape quittée ; glisser une carte vers une étape plus avancée ouvre la même fenêtre.
  • Fiche : « Historique » (en bas) retrace les dates et tâches faites ; téléphones et mails cliquables ; actions occasionnelles dans « Plus ▾ ».
  • Fiche pas à pas : en haut, la barre de progression (Qualification → Offre → Contrat → Onboarding → En service) ; chaque sous-étape reste cliquable pour sauter ou revenir. Dessous, « Étape en cours » : depuis combien de jours, qui l'a en main, une petite liste à cocher (certaines cases se cochent seules, ex. mail de demande copié) et un seul gros bouton pour passer à l'étape suivante (il marche même si tout n'est pas coché). Sorties (Perdu, No Go…) à côté. À droite : prochaine tâche, contact (appel ou mail en un clic), chiffres clés. Le reste (installations, caractéristiques, mail, historique) est replié et s'ouvre tout seul quand l'étape en a besoin. Dans la liste : les dates (RDV 1, RDV 2, offre remise) se tapent directement, une case cochée à la main garde son jour, et un petit bouton fait la chose (« Copier le mail », « Créer le fichier », « Compléter »). Après « Passer à… », la fiche se rouvre sur la nouvelle étape. Sur téléphone, la fiche prend tout l'écran et la progression tient sur une ligne.
  • Résumé de la semaine (« Ma semaine » sur Aujourd'hui, ou bouton du Tableau de bord) : signés, offres remises, dossiers qui ont avancé, nouveaux dossiers (avec les MWc entrés), appels, bloqués depuis plus de 15 jours (chez qui), tâches faites et à venir. « Copier pour mail / Teams » le met en forme pour ton manager.
  • Carte (bouton du Pipeline) : les installations en cours sur la carte de France, colorées par phase (qualification, offre, contrat, onboarding). Un clic sur un département liste ses centrales ; pratique pour repérer des centrales voisines à regrouper en lot ou préparer une tournée.
  • Mises en service à venir (Tableau de bord) : les MWc par trimestre sur deux ans, d'après la date de mise en service des fiches. Barre claire = en jeu ; barre foncée = probable, pondéré selon l'étape (pricing 25 %, offre en attente 40 %, KYC 60 %, signature 90 %, signé 100 %).
  • Doublons : quand une installation semble saisie deux fois, ou une société écrite de deux façons (« GAEC Dupont » / « Gaec Dupont SARL »), un bouton « Doublons · N » apparaît dans le Pipeline (aussi dans Ctrl K). Tu choisis ce que tu gardes et « Fusionner » : la fiche gardée reprend les cases que l'autre avait en plus, ses tâches et ses notes. « Ce sont des … différentes » les laisse tranquilles.
  • Présenter (Vue réunion) : la réunion en slides, à la manière d'un cabinet de conseil. La 1ʳᵉ slide donne tout : les chiffres clés, la répartition par phase et 4 messages (étapes, qui a la main, mises en service, dossiers bloqués), chacun avec la page qui le détaille (un clic y va). Ensuite une slide par message, avec un titre qui dit la conclusion et un « À retenir » ; les dossiers par phase en tableau ; une fiche par dossier en annexe. Flèches du clavier, F pour le plein écran, Échap pour fermer. « PowerPoint » télécharge les mêmes slides en .pptx : textes et tableaux modifiables, pour retoucher à la main avant de l’envoyer (il faut être connecté la première fois).
  • Marché (onglet) : un tableau de bord PowerKlock tout fait, toujours à jour (par défaut « Origination France » : forwards, prix capturés, M0, garanties d’origine). Le menu propose les autres modèles du site, ou ton propre tableau (colle son lien, copié dans General › API). « Copier pour un mail » résume le spot, le M0 et les prix capturés, sources comprises ; le Mode appel affiche les mêmes chiffres pour lancer la conversation. Hors ligne, les derniers chiffres lus restent affichés.
  • Notes express (dans chaque fiche) : tape ou colle tes notes en vrac (« P50 1200, MES juin 2027, 49300 Cholet, RDV 2 le 12/11, offre engageante, SPV : … »). L'appli repère les chiffres et les dates, montre l'ancienne valeur à côté ; décoche ce qui ne va pas, puis « Remplir ». « Garder la note » la range dans l'Historique.
  • Mode appel (bouton dans la case Contact de la fiche) : le numéro en grand, ce qu'il faut aborder à cette étape, les cases encore vides à demander (tu tapes la réponse sur place), tes notes avec les chiffres repérés au vol. « Terminer l'appel » remplit les cases cochées et garde l'appel (avec sa durée) dans l'Historique.
  • Cartes du pipeline : chaque colonne est découpée en sous-étapes (« Pricing · 2 »). Chaque carte dit la prochaine action (« → En attente d'Ops : … »), qui l'a en main (À moi, Ops, Juridique, Client, Direction) et depuis combien de jours (en orange au-delà de 15 j). En haut : « À moi · En attente des autres · Bloqués > 15 j ». Le Tableau de bord ajoute « Qui a la main » : combien de dossiers attendent chez moi, Ops, le Juridique, le producteur ou la Direction, depuis combien de jours.
  • Lots : dans la fiche d'une demande, section « Installations », coche quelques centrales, donne un nom (ex. « Lot 1 — toitures ») et « Faire un lot » : le lot avance à son rythme, avec sa propre carte, sans quitter la demande. Une installation qu'on fait avancer seule a aussi sa carte, avec « ↳ demande … » pour revenir à l'ensemble.
  • Copier-coller (partout) : « Copier ligne Pipe » (37 colonnes) ou « Copier ligne BDD » (91 colonnes), puis clic en colonne A d'une ligne vide et Ctrl+V.
  • Pont Excel (sur l'ordinateur) : « Envoyer au Pipe / à la BDD Excel » écrit directement dans les fichiers synchronisés avec SharePoint. Une ligne existante (même producteur + centrale) est mise à jour, sinon elle est ajoutée ; les formules ne sont jamais écrasées.
  • Installation du pont : Réf. & data → Pont Excel. Télécharge les deux fichiers dans un même dossier, double-clique sur le .bat, choisis les deux Excel, recopie la clé. Laisse la fenêtre ouverte (réduite).
  • Excel partagé avec des collègues : le pont n'écrase jamais une case modifiée par quelqu'un d'autre ; il te la montre avec Garder / Remplacer (et Fusionner pour les commentaires). Une ligne Perdu, Abandonné, No Go ou Résilié n'est jamais modifiée : un re-pricing ajoute une ligne (question si la ligne a moins de 6 mois). Un renouvellement a sa propre ligne. Une copie du fichier est gardée avant chaque écriture (dossier « Sauvegardes pont », 3 dernières).

Portefeuille

  • Paliers de l'objectif : quand le volume signé de l'année franchit 75 %, 90 % puis 100 % de l'objectif du Suivi, une animation (grimpeur, fusée, trophée) et un résumé prêt à copier pour ton manager. Une seule fois par palier.
  • Fiche d'une centrale : un clic sur une centrale (carte, tableau des installations, « Contrats qui finissent ») ouvre sa fiche complète, détails et caractéristiques ouverts. Si elle n'existe pas encore dans l'appli, elle est créée à partir de la ligne du Suivi (producteur, puissance, P50, dates, statut).
  • Charge le fichier « Suivi Agrégation » (ou « Lire depuis l'Excel » avec le pont). Il reste sur l'appareil, il n'est pas envoyé sur GitHub.
  • Volumes par année et par cadre face à l'objectif, développeurs, régions, échéances, table filtrable.
  • Renouvellements : une tâche par développeur et date de fin pour les contrats qui se terminent dans les 6 mois (réglable). « Remettre dans le pipeline » recrée l'installation à l'étape Pricing ; « Non renouvelé » l'enregistre comme perdue (dans les Sorties du pipeline) et clôt sa tâche de renouvellement.
  • Les contrats d'un producteur apparaissent aussi sur sa fiche dans Contacts (bouton ⓘ).

Contacts

  • Carte de visite : le bouton ouvre l'appareil photo (ou un fichier image) ; le texte est lu sur l'appareil et le contact s'ouvre pré-rempli, à vérifier avant d'enregistrer.
  • Depuis le téléphone : importe le fichier de contacts exporté par le téléphone (.vcf) ; sur Android, choix direct dans le répertoire. Les contacts déjà connus (même mail, téléphone ou nom dans la même société) ne reçoivent que leurs cases vides ; rien n'est effacé. « Vers le téléphone » fait l'inverse.
  • Tri en cliquant sur les en-têtes Contact, Société, Pertinence. Clic sur un nom = la fiche ; l'icône copie le mail ou le téléphone.
  • « Coller une signature » crée un contact depuis une signature (texte ou image).
  • Vers le téléphone : fichier .vcf des contacts jamais exportés (les doublons de l'app sont fusionnés). Après le tout premier import sur un téléphone qui avait déjà des contacts, lance « Fusionner les doublons » du téléphone.

Sur le téléphone

  • Réseau aussi sur le téléphone (barre du bas) : pincer pour zoomer, toucher un point pour ses liens, deux fois pour sa fiche.
  • Ouvre tomsremy.github.io/ToDo/mobile.html puis « Sur l'écran d'accueil ». Version allégée : Aujourd'hui, Tâches, Contacts, Portefeuille, Pipeline (lecture) et la note.
  • Mêmes données que l'ordinateur dès que la synchro est activée sur le téléphone (une fois, dans la version complète, onglet Réf. & data).
  • Pour changer l'icône après une mise à jour : retirer l'app de l'écran d'accueil puis la rajouter.

Synchro et sécurité

  • Rappel de sauvegarde : sans synchro GitHub, si aucun export n'a été fait depuis un mois, Aujourd'hui propose « Exporter maintenant » (ou « Plus tard » pour une semaine).
  • Les données passent par ton repo GitHub privé (TomSRemy/todo-data) avec un token stocké seulement dans le navigateur. Le code de l'app est public, tes données non.
  • Chaque appareil garde une copie locale : l'app marche sans réseau, puis se resynchronise (toutes les 5 minutes, et en quittant l'app).
  • Si le même champ a été modifié sur deux appareils, la version la plus récente gagne et le cas est listé dans Réf. & data → Conflits.
  • Sauvegarde : Réf. & data → Exporter (fichier JSON complet).
